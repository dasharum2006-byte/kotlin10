# Задание 10 — «Корзина онлайн-магазина» (Jetpack Compose)

Проект: `~/AndroidStudioProjects/10`, пакет `com.example.a10`.

## Какие ошибки были в исходном коде и как исправлены

| № | Ошибка джуна | Почему это баг | Исправление |
|---|--------------|----------------|-------------|
| 1 | `totalSum` и `productSize` — поля класса, которые **инкрементировались прямо в теле композиции** (`totalSum += product.price` внутри `for`) | Тело composable-функции выполняется при **каждой** рекомпозиции. Переменные не сбрасывались, поэтому сумма росла при каждом перерисовывании → «с пользователей требуют больше денег». Плюс это побочный эффект в композиции (нарушение идемпотентности) | `totalSum = products.sumOf { it.price }`, `productSize = products.size` — вычисляемые значения из единственного источника правды (`Cart.products`) |
| 2 | `Toast.makeText(...).show()` вызывался **внутри композиции** `AddProductSection` | Побочный эффект при композиции: Toast показывался/дублировался на каждой рекомпозиции, а не по событию | Toast перенесён в `LaunchedEffect(totalSum)` — эффект запускается только при изменении суммы |
| 3 | Условие `if (totalSum > 500)` висело на композиции, а не на событии добавления | Toast мог «мигать» при любых изменениях UI | Проверка внутри `LaunchedEffect`, порог вынесен в константу `FREE_DELIVERY_THRESHOLD = 500` |
| 4 | Состояние хранилось в `remember` | При смене конфигурации (поворот экрана) корзина сбрасывалась | `rememberSaveable(stateSaver = CartSaver)` + `listSaver`, который сохраняет корзину в Bundle плоским списком `id, name, price` |
| 5 | `id = products.size` для нового товара | После удаления товара id повторялись (дубликаты ключей при выводе списков) | `id = (products.maxOfOrNull { it.id } ?: -1) + 1` |
| 6 | UI «одним куском» в `ShoppingCartScreen`, данные брались из неявных полей класса (не идемпотентно) | Лишние рекомпозиции, непредсказуемость | Экран разбит на идемпотентные composable-функции с явными параметрами: `ProductListSection`, `TotalSumSection`, `AddProductSection`, `RemoveProductSection` |
| 7 | `products.dropLast(1)` / добавление без защиты | Удаление из пустой корзины, изменение состояния без единой точки обновления | Обновление только через `cart = cart.copy(products = ...)`, `onRemove` защищён `if (products.isNotEmpty())` |

## Что должно работать (по методичке)

1. Кнопка **«Добавить товар»** добавляет новый товар в корзину.
2. Если сумма заказа больше 500 — показывается Toast **«Доставка бесплатная!»**.
3. Кнопка **«Удалить товар»** видна только когда в корзине есть товары.
4. **«Удалить товар»** удаляет последний товар.
5. Сумма и количество товаров всегда соответствуют содержимому корзины (в т.ч. после поворота экрана).
